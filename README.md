# linguatravel-site

https://linguatravel.app — LinguaTravel tanıtım sitesi, gizlilik, destek ve web uygulaması (`/uygulama`).
Cloudflare Pages `linguatravel-site` projesi `public/` klasörünü yayınlar; `main`'e push = yayın.

Web uygulaması özel uygulama deposunda derlenir ve buraya kopyalanır: `sh scripts/web-yayin.sh` (linguatravel deposunda), sonra burada commit + push.
Bu depo açıktır; uygulamanın kaynak kodu burada değil.
